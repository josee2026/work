CSS Properties Research Report

Introduction

CSS stands for Cascading Style Sheets. It is used to design and style web pages. CSS controls colors, fonts, backgrounds, layouts, spacing and animations.

1. Text and Font Properties

These properties control the appearance of text.

  • color: Changes text color. Values: red, blue, black.
  • font-family: Changes font type. Values: Arial, Times New Roman.
  • font-size: Changes text size. Values: 12px, 16px, 20px.
  • font-weight: Controls text thickness. Values: normal, bold, 100–900.
  • font-style: Changes text style. Values: normal, italic, oblique.
  • line-height: Controls line spacing. Values: normal, 1.5, 20px.
  • text-align: Aligns text. Values: left, right, center, justify.
  • text-decoration: Decorates text. Values: none, underline, overline.
  • text-transform: Changes capitalization. Values: uppercase, lowercase, capitalize.

Example

p { color: blue; font-size: 18px; text-align: center; }

2. Box Model Properties

The box model describes how HTML elements are displayed using content, padding, border and margin.

  • width: Sets element width. Values: 100px, 50%, auto.
  • height: Sets element height. Values: 100px, 200px, auto.
  • margin: Adds outside spacing. Values: 10px, 20px, auto.
  • padding: Adds inside spacing. Values: 10px, 15px, 20px.
  • border: Adds a border. Values: 1px solid black, 2px dashed red.
  • box-sizing: Controls box dimensions. Values: content-box, border-box.

Example

.box { width: 300px; height: 150px; margin: 20px; padding: 15px; border: 2px solid black; }

3. Background Properties

These properties control the background of webpage elements.

  • background-color: Sets background color. Values: red, blue, white.
  • background-image: Adds an image. Values: url("image.jpg"), none.
  • background-size: Controls image size. Values: cover, contain, auto.
  • background-position: Sets image position. Values: center, top, bottom.
  • background-repeat: Controls image repetition. Values: repeat, no-repeat.
  • background-attachment: Controls background scrolling. Values: fixed, scroll.

Example

body { background-color: lightblue; background-image: url("image.jpg"); background-size: cover; }

4. Layout and Positioning

These properties control the arrangement and position of elements.

  • display: Controls element display. Values: block, inline, flex, grid, none.
  • position: Sets positioning method. Values: static, relative, absolute, fixed, sticky.
  • top: Sets distance from the top. Values: 10px, 20px, auto.
  • right: Sets distance from the right. Values: 10px, 20px, auto.
  • bottom: Sets distance from the bottom. Values: 10px, 20px, auto.
  • left: Sets distance from the left. Values: 10px, 20px, auto.
  • z-index: Controls stacking order. Values: 1, 2, 10, auto.
  • float: Positions elements left or right. Values: left, right, none.
  • overflow: Controls extra content. Values: visible, hidden, scroll, auto.

Example

.box { position: absolute; top: 20px; left: 30px; z-index: 2; }

5. Flexbox Properties

Flexbox is a CSS layout system used to arrange elements in rows or columns.

  • display: Activates Flexbox. Values: flex, inline-flex.
  • justify-content: Aligns items along the main axis. Values: center, flex-start, flex-end, space-between.
  • align-items: Aligns items along the cross axis. Values: center, stretch, flex-start, flex-end.
  • flex-direction: Sets item direction. Values: row, column, row-reverse, column-reverse.
  • flex-wrap: Controls wrapping. Values: nowrap, wrap, wrap-reverse.
  • gap: Adds space between items. Values: 10px, 20px.
  • flex-grow: Controls item growth. Values: 0, 1, 2.
  • flex-shrink: Controls item shrinking. Values: 0, 1, 2.

Example

.container { display: flex; justify-content: center; align-items: center; flex-direction: row; gap: 20px; }

6. Grid Properties

CSS Grid is a layout system used to organize elements into rows and columns.

  • display: Activates Grid. Values: grid, inline-grid.
  • grid-template-columns: Defines columns. Values: 1fr 1fr, repeat(3, 1fr).
  • grid-template-rows: Defines rows. Values: 100px, auto.
  • gap: Adds space between grid items. Values: 10px, 20px.
  • row-gap: Adds space between rows. Values: 10px, 20px.
  • column-gap: Adds space between columns. Values: 10px, 20px.
  • grid-area: Places an item in a grid area. Values: header, main, sidebar.
  • grid-column: Controls column placement. Values: 1 / 3, span 2.
  • grid-row: Controls row placement. Values: 1 / 3, span 2.

Example

.container { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

7. Visual Effects Properties

These properties add attractive visual effects to webpages.

  • opacity: Controls transparency. Values: 0, 0.5, 1.
  • box-shadow: Adds shadows. Values: 2px 2px 5px gray, none.
  • border-radius: Rounds corners. Values: 5px, 10px, 50%.
  • transform: Moves or rotates elements. Values: rotate(), scale(), translate(), skew().
  • transition: Makes changes smooth. Values: 0.3s, 1s, ease, linear.
  • animation: Creates animated effects. Values: animation-name, duration, timing-function.
  • filter: Applies visual effects. Values: blur(), grayscale(), brightness().

Example

.box { opacity: 0.8; box-shadow: 5px 5px 10px gray; border-radius: 10px; transition: 0.5s; }

8. Responsive Design

Responsive design allows websites to adjust automatically to different screen sizes, such as computers, tablets and phones.

CSS Units

  • px: Fixed pixel measurement. Example: 20px.
  • %: Relative to the parent element. Example: 50%.
  • em: Relative to the font size. Example: 2em.
  • rem: Relative to the root font size. Example: 1.5rem.
  • vw: Relative to viewport width. Example: 50vw.
  • vh: Relative to viewport height. Example: 100vh.

Media Queries

Media queries apply different styles depending on screen size or device characteristics.

  • max-width: Applies styles below or at a specified width.
  • min-width: Applies styles above or at a specified width.
  • orientation: Detects portrait or landscape screen orientation.

Example

@media screen and (max-width: 600px) { .container { width: 100%; } }

Conclusion

CSS properties are important in web development because they help create attractive, organized, interactive and responsive websites. They control text, backgrounds, spacing, positioning, layouts and visual effects.
